# Triage labels

Mapping 5 canonical triage roles sang labels của issue tracker.

| Role | Label trong tracker | Ý nghĩa |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer cần đánh giá issue |
| `needs-info` | `needs-info` | Chờ người báo cung cấp thêm thông tin |
| `ready-for-agent` | `ready-for-agent` | Spec đầy đủ, sẵn sàng cho AFK agent |
| `ready-for-human` | `ready-for-human` | Cần người triển khai |
| `wontfix` | `wontfix` | Không xử lý |

Khi skill nhắc tới một role, dùng label tương ứng trong bảng.

Sửa cột “Label trong tracker” nếu repo đổi label vocabulary.
